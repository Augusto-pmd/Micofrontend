Estructura de navegación del panel admin

Las 3 opciones definen cómo van a moverse entre secciones en el día a día

A — Sidebar de íconos

Panel lateral estrecho con íconos. Máximo espacio para el contenido. Hover muestra el label. Muy común en SaaS ops tools (Notion, Linear, Vercel). Ideal para desktop.

B — Top nav horizontal

Barra superior con todas las secciones visibles. Familiar (se parece al portal del cliente). Funciona bien cuando hay pocas secciones (≤7). Deja todo el ancho para el contenido.

● Dashboard
○ Reservaciones
○ Inventario
○ Clientes
○ Accesos
○ Revenue

C — Sidebar con labels (recomendado)

Panel lateral con texto visible siempre. Ves dónde estás de un vistazo, navegás rápido. Permite agrupar: Operaciones / Finanzas / Configuración. Más legible para uso diario intenso.
